The FMS D.O.O.

The Fidelity Diagnostic Method

A repeatable logic sequence that prevents callbacks and ensures nothing is missed. Every technician uses it. Every review references it. Every callback gets traced against it.

Power → Airflow → Electrical → Refrigerant → Controls → Environment

1

Power Verification

Confirm voltage at source and load. Verify disconnects, fuses, breaker behavior. Don't test a system that isn't powered—confirm, don't assume.

2

Airflow Assessment

Filter condition, blower response, damper position. Static pressure if needed; return vs supply balance. Never skip airflow and jump to refrigerant—it voids the logic.

3

Electrical Systems

Capacitance, contactor integrity, wiring condition. Visually inspect terminals and connections. Test coils, relays, amp draw under load.

4

Refrigerant Analysis

Only after airflow is confirmed. Measure superheat and subcool—don't just look at pressure. Note TXV behavior, possible underfeed or overfeed indicators.

5

Controls Verification

Verify thermostat logic, communication voltage. Check sensor data, staging, and interlocks. Observe expected vs actual system response.

6

Environmental Factors

Assess rooftop loading, grease accumulation, ambient interference. Validate drainage slope, humidity factors, airflow path obstructions. Site-specific factors change system behavior.
